2
운임 조회 방법
1
고시 시기 선택 — 26년 8월 1일 이후 적용 권장
2
출발 거점 드롭다운에서 출발지 선택 (예: 평택항 기점)
3
행선지 검색창에 목적지 주소 또는 장소명 입력
4
자동완성 목록에서 해당 장소 클릭
5
20FT / 40FT 안전운임 및 견적가 자동 표시
💡 장소명(예: 다이소 안성물류센터)을 클릭하면 화주명이 자동으로 저장됩니다.
💡 거점을 변경해도 검색된 행선지는 유지되며 새 거점으로 재계산됩니다.

4
쉐어율 설정

운수사와 화주 사이의 마진을 조정할 때 사용합니다.
청구운임 = 안전운임 − (마진 × 쉐어율)  |  마진 = 안전운임 − 위탁운임(화주제출용)

쉐어율계산 방식예시 (안전운임 100,000 / 위탁 80,000)
0% (미설정)할인 없음청구운임 = 100,000원
30%마진 20,000원의 30% = 6,000원 할인청구운임 = 94,000원
50%마진 20,000원의 50% = 10,000원 할인청구운임 = 90,000원
100%마진 20,000원 전액 할인청구운임 = 80,000원
💡 복사 및 견적서에 안전운임과 청구운임이 함께 표시됩니다.
5
견적 카트 사용법

여러 건의 견적을 한 번에 모아서 관리할 수 있습니다.

1
운임 조회 후 화면 하단 "🛒 견적 담기" 버튼 클릭
2
우측 상단 "🛒 견적 카트" 버튼 클릭하여 카트 열기
3
담긴 견적 목록 확인 (출발거점, 운임구간, 20FT/40FT 견적가)
4
불필요한 건은 🗑️ 버튼으로 삭제
5
카트에서 복사, 엑셀 저장, PDF 저장, 이력 남기기 가능
💡 견적 카트는 여러 구간을 한 번에 담아 하나의 견적서로 만들 때 유용합니다.
6
견적서 저장 (PDF / 엑셀)
버튼설명용도
📄 PDF 저장견적서를 PDF 파일로 저장카카오톡, 이메일 전송
📥 엑셀 저장견적서를 엑셀(.xlsx)로 저장A4 가로 1페이지 인쇄
📋 견적 내용 복사운임 내용을 텍스트로 복사카카오톡 빠른 전송
🚚 운수사 거래용 복사운수사간 거래 기준 텍스트 복사운수사 전달용
ℹ️ 쉐어율이 설정된 경우 견적서에 안전운임과 청구운임이 함께 표시됩니다.
7
견적 이력 남기기

견적 카트에서 이력을 저장하면 회사 구글 시트에 자동 기록됩니다.

1
견적 카트 열기 → "📝 이력 남기기" 버튼 클릭
2
담당자 이름 입력 (예: 홍길동 대리)
3
운임 방식 선택 (안전운임 / 운수사간 / 쉐어율)
4
사무소 선택 (영업팀 / 평택본사운송팀 / 인천사무소 등)
5
수신처 및 화주명 확인 또는 직접 입력
6
"💾 이력 저장" 버튼 클릭
💡 저장된 이력은 회사 모든 직원의 견적 이력 탭에서 실시간 확인 가능합니다.
8
견적 이력 조회

상단 "견적 이력" 탭을 클릭하면 저장된 모든 이력을 조회할 수 있습니다.

기능설명
🔍 검색창화주명, 담당자, 구간 키워드로 검색
담당자 필터특정 담당자의 이력만 필터링
사무소 필터특정 사무소의 이력만 필터링
기간 필터26년 2월 / 26년 8월 고시시기로 필터링
상세 버튼해당 견적의 할증 상세내역, 안내사항 전체 확인
재견적 버튼기존 이력을 다른 조건으로 다시 계산
🗑️ 삭제 버튼이력 삭제
9
재견적 방법

기존 견적 이력을 새로운 조건으로 다시 계산할 때 사용합니다.

1
견적 이력 탭에서 재견적할 이력의 "재견적" 버튼 클릭
2
팝업에서 원본 견적 정보 확인
3
새 조건 설정: 고시 시기 / 운임 방식 / 할증 항목 / 사사오입 여부
4
"🔄 계산" 버튼 클릭 → 재견적 결과 확인
5
"💾 새 이력으로 저장" 클릭 → 새 이력으로 저장됨
💡 재견적 저장 시 비고란에 "재견적 (원본: 날짜)"가 자동으로 표시됩니다.
